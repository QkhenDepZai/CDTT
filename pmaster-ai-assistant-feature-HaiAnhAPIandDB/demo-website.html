Đây là website "khách hàng" giả lập

Trang này chỉ để test xem chatbot có nhúng và hoạt động đúng khi đặt vào một website hoàn toàn khác (khác domain với backend) hay không. Nội dung trên trang không quan trọng — mục tiêu là bấm vào nút chat ở góc phải dưới màn hình và kiểm tra toàn bộ luồng: giao diện → gửi API → backend Flask → Gemini → trả lời ngược lại.

Checklist khi test

Mở DevTools (F12) → tab Console và Network trước khi bấm chat, để theo dõi:

  • Có lỗi CORS trong Console không?
  • Request POST tới /api/chat có gửi đi không, status code là gì?
  • Response trả về có đúng field reply, conversation_id không?
  • Gửi 2-3 câu hỏi liên tiếp — bot có nhớ ngữ cảnh câu trước không?
